**Project Title:** Web Application Security Risk Prioritization and Reporting System  
**Intended Environment:** Educational, Academic Laboratory, and Authorized Assessment Environments Only.

---

### Strict Usage Policy

1. **Explicit Permission Required:**  
   This security assessment software must strictly be utilized against target web applications, servers, or APIs that you personally own or where you have acquired explicit, written authorization from the system owner to conduct security testing.

2. **No Custom Attack Code / No Live Attacks:**  
   This application is designed as a passive security risk prioritization, aggregation, and reporting engine. It processes scanner output (such as OWASP ZAP JSON reports) and calculates quantitative risk scores. It does not generate destructive exploit payloads or launch unauthorized denial-of-service or intrusion attempts.

3. **Academic & Research Purpose:**
